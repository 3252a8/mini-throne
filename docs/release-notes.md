First public test release of Mini Throne for Windows x64 and its Minishop plugin.

- Minimal interface with system proxy, TUN and full Throne controls in Settings.
- Manual subscriptions and individual servers; confirmed subscription deep-link imports.
- GitHub updates authenticated with a pinned Ed25519 key and executable hashes.
- One-use installer enrollment, branding and subscriptions from Minishop.
- Automatic installer cache and Windows installation guides, including Remnawave Subscription Page.
- Repository URL installation through the signed ready-package index.

The Windows executable is not Authenticode signed; SmartScreen may show an unknown publisher.
Plugin runtime: Linux x86_64, Python 3.12; Core revision 67357d3cfad4a430bfd66fbb507ddad390e5eb73.
Alpha clients need one manual installation to enable the new update channel.
